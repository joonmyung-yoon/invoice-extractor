# Invoice Extractor 설치 방법 (macOS)

## 1. 먼저 확인할 것

이 앱은 **그 PC에 설치된 Claude Code** 를 사용합니다. 없으면 동작하지 않습니다.

터미널에서 확인:

```bash
claude --version
```

없다면 먼저 Claude Code 를 설치하고 로그인해 주세요.

## 2. 설치

1. `Invoice Extractor_0.1.0_universal.dmg` 를 더블클릭
2. 앱 아이콘을 **응용 프로그램** 폴더로 끌어다 놓기

## 3. 첫 실행 — ⚠️ 그냥 더블클릭하면 안 열립니다

이 앱은 Apple 에 등록된 개발자 인증서로 서명되어 있지 않습니다. 그래서 처음 열 때
**"개발자를 확인할 수 없기 때문에 열 수 없습니다"** 또는 **"손상되었기 때문에 열 수 없습니다"**
라는 경고가 뜹니다. 앱에 문제가 있어서가 아니라, 인터넷으로 받은 미서명 앱에 macOS 가
자동으로 붙이는 표시(격리 속성) 때문입니다.

**여는 방법 — 아래 둘 중 하나:**

### 방법 A) 우클릭으로 열기 (간단)

1. 응용 프로그램 폴더에서 앱을 **우클릭(또는 Control+클릭)** → **열기**
2. 경고창에서 다시 **열기** 클릭

한 번만 하면 이후로는 더블클릭으로 열립니다.

### 방법 B) 위 방법으로도 안 열릴 때 (터미널)

"손상되었습니다" 가 뜨면 방법 A 로 안 되는 경우가 있습니다. 터미널에 아래를 붙여넣으세요:

```bash
xattr -dr com.apple.quarantine "/Applications/Invoice Extractor.app"
```

## 4. 처음 설정

앱을 열고 **설정** 탭에서:

1. **Claude Code** — 자동으로 찾습니다. 못 찾으면 `claude` 경로를 직접 입력
   (터미널에서 `which claude` 로 확인)
2. **구글시트 연결** — 서비스 계정 JSON 키 파일을 넣고, 마스터 시트 URL 입력 → **연결 테스트**
3. **지금 동기화** — 벤더·카드·지점·COA 매핑을 받아옵니다

키를 처음 넣을 때 macOS 가 **키체인 암호를 한 번 물어봅니다.** "항상 허용" 을 누르면 다음부터
묻지 않습니다.

## 5. 쓰는 순서

1. **추출** 탭에 PDF 를 끌어다 놓기
2. 노란색 칸(확인 필요)을 채우기 — 주로 지점(LOCATION)
3. 표에서 셀을 드래그해 선택하고 `⌘C` 로 복사 → 구글시트에 붙여넣기
4. **장부에 저장** → **장부** 탭에서 **구글시트와 동기화**

추출은 19페이지 기준 3~4분 정도 걸립니다. 다른 탭으로 옮겨도 계속 진행됩니다.

---

## 자주 겪는 문제

**"claude CLI 를 찾지 못했습니다"**
GUI 앱은 터미널의 PATH 를 물려받지 못할 때가 있습니다. 설정에서 경로를 직접 넣어주세요.

**"시트에 접근할 수 없습니다 (403)"**
구글시트 **공유**에서 서비스 계정 이메일이 **편집자**로 들어가 있는지 확인하세요.
이메일은 설정 화면에 표시되고 복사 버튼이 있습니다.

**앱을 껐는데 추출이 진행 중이었다면**
다음에 켤 때 해당 작업이 **중단됨**으로 표시됩니다. **이력** 탭에서 **다시 추출**을 누르면
PDF 변환 없이 바로 다시 시도합니다.

**용량이 커졌을 때**
설정 → 저장 용량 → **페이지 이미지 모두 비우기**. 추출된 표와 장부는 지워지지 않습니다.
