# Invoice Extractor 설치 방법

## macOS

### ⚠️ 먼저 알아두실 것

이 앱은 Apple 개발자 인증서로 서명되어 있지 않습니다. 그래서 인터넷에서 받으면
macOS 가 **"Apple이 악성 소프트웨어가 없는지 확인할 수 없습니다"** 라며 실행을 막습니다.
앱에 문제가 있어서가 아니라, 서명 없는 앱에 macOS 가 자동으로 붙이는 격리 표시 때문입니다.

**macOS 15(Sequoia) 부터는 "우클릭 → 열기" 로 열리지 않습니다.** 아래 방법을 쓰세요.

### 설치

1. `.dmg` 를 열고 앱을 **응용 프로그램** 폴더로 끌어다 놓기
2. 아래 둘 중 하나로 격리 해제

#### 방법 0) 함께 들어 있는 `설치하기.command` (가장 쉬움)

`설치하기.command` 를 **우클릭 → 열기 → 열기** 하면 아래 과정을 대신 해 줍니다.
(다운로드한 파일이라 첫 실행에는 더블클릭이 아니라 우클릭으로 열어야 합니다.)

#### 방법 A) 터미널 (가장 확실함)

터미널에 붙여넣고 실행:

```bash
xattr -dr com.apple.quarantine "/Applications/Invoice Extractor.app"
```

이후 더블클릭으로 열립니다.

#### 방법 B) 시스템 설정

1. 앱을 한 번 더블클릭 → 차단 경고가 뜨면 **완료(Done)** 클릭
   (**"휴지통으로 이동" 을 누르지 마세요**)
2. **시스템 설정 → 개인정보 보호 및 보안** 열기
3. 아래로 스크롤 → *"'Invoice Extractor'이(가) 차단되었습니다"* 옆 **그래도 열기** 클릭
4. 다시 앱 실행 → **열기** 클릭

> 위 두 방법이 번거로우면 Apple Developer Program($99/년) 에 가입해 서명·공증하면
> 받는 사람이 그냥 더블클릭으로 열 수 있습니다.

## Windows

`.msi` 또는 `.exe` 를 실행하세요.
**"Windows에서 PC를 보호했습니다"** 가 뜨면 **추가 정보 → 실행**.

---

## 공통: Claude Code 가 필요합니다

이 앱은 그 PC에 설치되어 **로그인된 Claude Code** 를 사용합니다.
터미널에서 아래가 동작하는지 먼저 확인하세요:

```bash
claude --version
```

없다면 Claude Code 를 먼저 설치하고 로그인해 주세요.

## 처음 설정

앱을 열고 **설정** 탭에서:

1. **Claude Code** — 자동으로 찾습니다. 못 찾으면 `which claude` 결과를 직접 입력
2. **구글시트 연결** — 서비스 계정 JSON 키 파일을 넣고 시트 URL 입력 → **연결 테스트**
3. **시트 초기화** → **지금 동기화**

## 쓰는 순서

1. **추출** 탭에 PDF 를 끌어다 놓기 (19페이지 기준 3~4분, 다른 탭 가도 계속 진행)
2. 노란 칸(확인 필요)을 채우기 — 주로 지점(LOCATION)
3. 왼쪽 체크박스로 행을 고르고 **복사** → 구글시트에 붙여넣기
4. **장부에 저장** → **장부** 탭에서 **구글시트와 동기화**

## 자주 겪는 문제

**"claude CLI 를 찾지 못했습니다"**
GUI 앱은 터미널의 PATH 를 물려받지 못할 때가 있습니다. 설정에서 경로를 직접 넣으세요.

**"시트에 접근할 수 없습니다 (403)"**
구글시트 **공유**에 서비스 계정 이메일이 **편집자**로 들어가 있는지 확인하세요.
이메일은 설정 화면에 표시되고 복사 버튼이 있습니다.

**추출 중에 앱을 껐다면**
다음에 켤 때 **중단됨**으로 표시됩니다. **이력** 탭에서 **다시 추출**을 누르면
PDF 변환 없이 바로 다시 시도합니다.

**용량이 커졌을 때**
설정 → 저장 용량 → **페이지 이미지 모두 비우기**. 추출 결과와 장부는 지워지지 않습니다.
