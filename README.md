# Invoice Extractor

스캔된 인보이스 PDF 를 로컬에 설치된 Claude Code 로 읽어 표로 뽑아내고, 앱 안에서 수정한 뒤
복사·저장하는 데스크톱 앱. macOS / Windows 겸용 (Tauri).

## 어떻게 동작하나

```
PDF ──pdf.js──▶ 페이지 PNG ──▶ 앱 데이터 폴더의 작업 디렉터리
                                      │
                                claude -p (1회 실행, MCP 차단)
                                      │
                              extracted.json
                                      │
                      마스터 테이블로 결정적 보정 (벤더명·카드·COA·결제수단)
                                      │
                            편집 가능한 표 ──▶ 복사 / .xlsx / 장부
                                                          │
                                                  로컬 SQLite (1차)
                                                          │
                                                   구글시트 동기화
```

- **PDF 렌더링은 앱이 직접 한다.** Claude Code 의 PDF 읽기는 시스템에 poppler 가 깔려 있어야
  하는데, 사용자 PC 마다 그걸 요구할 수 없다. pdf.js 로 페이지를 PNG 로 만들어 이미지로 넘기면
  외부 의존성이 없고 해상도·회전도 앱이 제어할 수 있다.
- **긴 변 1568px 로 렌더링한다.** Claude 가 이미지를 그 크기로 줄여서 보기 때문에 더 크게 만들면
  디스크와 전송량만 늘고 인식률은 그대로다.
- **대화 세션은 남지 않는다.** 항상 `-p`(비대화 1회 실행)로 부르고, `--strict-mcp-config` 로
  사용자 환경의 MCP 서버를 차단하며, 허용 도구를 `Read,Write` 로 묶어 작업 폴더 밖으로 못 나가게
  한다.

## 처음 설정

### 1. Claude Code

PC 에 설치되어 있고 로그인되어 있어야 한다. 앱이 자동으로 찾지 못하면 설정 화면에서 경로를
직접 지정한다.

### 2. 구글시트 (매핑 기준표 + 장부)

서비스 계정 방식이다. 직원들은 구글 로그인을 하지 않는다.

1. https://console.cloud.google.com → 새 프로젝트 (예: `invoice-extractor`)
2. `Google Sheets API` 사용 설정
3. **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기** (역할은 지정하지 않아도 된다)
4. 만든 계정 → **키 → 키 추가 → JSON** → 파일 다운로드
5. 구글시트를 만들고 **공유** → 그 서비스 계정 이메일을 **편집자**로 추가
6. 앱 설정 화면에서 키 파일을 넣고 시트 URL 을 입력 → **연결 테스트** → **시트 초기화**

키 파일은 OS 자격증명 저장소(macOS 키체인 / Windows 자격 증명 관리자)에 들어간다.
앱 폴더나 저장소에는 남지 않는다.

시트에는 탭이 5개 생긴다:

| 탭 | 용도 |
|---|---|
| `Vendors` | 벤더 정식표기 / 별칭 / 결제수단 / 기본 카드 / 기본 COA |
| `Cards` | 카드 끝 4자리 → CARD_ID |
| `Locations` | 지점 코드 / 배송지 상호 / 주소 단서 |
| `COA` | 허용 계정과목 |
| `Records` | 확정 내역 장부 (동기화로 쌓인다) |

`master_sheet/` 폴더에 초기 데이터가 TSV 로 들어 있다. 앱 없이 손으로 채우려면 각 파일을
해당 탭 A1 에 붙여넣으면 된다.

## 쓰는 순서

1. **추출** — PDF 를 드롭 → 페이지 변환 → Claude Code 추출 → 표
2. 노란 칸(확인 필요)을 채운다. 「확인 필요 N칸」 버튼으로 그 행만 볼 수 있다.
3. 셀을 끌어 범위 선택 후 `⌘/Ctrl+C` 로 복사, 또는 「전체 복사」로 구글시트에 붙여넣기
4. **장부에 저장** — 로컬에 먼저 쌓인다 (인터넷 불필요)
5. **장부** 화면에서 **구글시트와 동기화** — 양쪽에 없는 행을 서로 채운다

## 정확도

샘플 19페이지(정답 14행)로 측정: **필드 기준 94.9%**, 10/14 행 완전일치.
마스터 테이블 적용 시 벤더명 표기·기본 카드가 결정적으로 교정되어 **98%** 수준.

남는 오차는 대부분 **지점(LOCATION)** 이다. 문서에 손글씨나 배송지 표기가 없으면 근거가 없어서
추론이 불가능하다. 그래서 이 앱은 지점을 추측하지 않고 **비워두고 노란색으로 표시**한다.
틀린 값이 조용히 들어가는 것보다 빈 칸이 낫다.

`Locations` 탭의 `name` / `hints` 를 채울수록 자동 판별률이 올라간다.

## 알려진 특성

- **손글씨 지점 분할**: COSTCO 영수증처럼 하단에 `IFO - 3040-13  457.98` 식으로 손글씨가 있으면
  한 영수증이 여러 행으로 쪼개진다. 분할 합계가 영수증 총액과 맞는지 앱이 다시 계산해서
  틀리면 빨간 경고를 띄운다.
- **여러 장짜리 인보이스**: `CONT. ON PAGE 2` / `LAST PAGE` 를 인식해 한 건으로 묶는다.
  총액은 마지막 장에서 읽는다.
- **눕혀서 스캔된 페이지**: 그대로 인식한다.
- **DATE 는 진짜 날짜값으로 내보낸다.** `.xlsx` 저장 시 `mm/dd/yyyy` 서식이 적용된 날짜값이
  들어가므로 정렬·필터·기간 합계가 정상 동작한다. (샘플 파일은 미국식 `MM/DD` 를 `dd/mm` 으로
  잘못 파싱해 8월 데이터가 1~12월에 흩어져 있었다. 그 문제를 반복하지 않기 위한 것이다.)

## 개발

```bash
npm install
npm run tauri dev          # 개발 모드
npm run tauri build        # 배포 빌드 (.app / .dmg / .msi / .exe)
```

Rust 툴체인이 필요하다: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

### 구조

```
src/
  lib/pdf.ts            PDF → PNG 렌더링
  lib/defaultPrompt.ts  기본 추출 프롬프트 + 마스터 주입
  lib/normalize.ts      마스터 적용, 합계 검산, 페이지 커버리지 검사
  lib/export.ts         TSV / 텍스트 / xlsx (의존성 없는 최소 xlsx 작성기)
  views/                추출 · 장부 · 이력 · 프롬프트 · 설정
src-tauri/src/
  claude.rs             claude CLI 실행
  sheets.rs             서비스 계정 JWT → Sheets API v4
  db.rs                 SQLite (이력 · 프롬프트 · 장부 · 마스터 캐시)
  secrets.rs            OS 자격증명 저장소
```

## 저장 위치

- macOS: `~/Library/Application Support/com.scr.invoice-extractor/`
- Windows: `%APPDATA%\com.scr.invoice-extractor\`

PDF 페이지 이미지 · 추출 이력 · 프롬프트 · 장부가 여기 들어간다.
